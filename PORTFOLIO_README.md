# Vitta Hem Kumar - Personal Portfolio

A modern, responsive portfolio website built with React and Tailwind CSS, showcasing a minimalist warmth with editorial feel design philosophy.

## 🌟 Features

### Design & UX
- **Minimalist Warmth**: Clean, spacious design with sophisticated typography
- **Editorial Feel**: Asymmetrical layouts and unconventional grid systems
- **Professional Color Palette**: Off-white background (#F8F7F4), charcoal text (#222222), and deep teal accent (#008080)
- **Premium Typography**: Lora serif for headings, Inter for body text
- **Smooth Animations**: Fade-in on scroll, hover effects, and micro-interactions

### Pages & Components
- **Home**: Hero section with professional photo, featured projects showcase, and CTA
- **Work**: Filterable project grid with categories (UX Design, Web Development, AI/ML, Branding)
- **Project Details**: Detailed case studies with challenge, process, solution, and results
- **About**: Personal story, skills showcase, experience timeline, and testimonials
- **Contact**: Contact form with validation, social links, and professional information

### Technical Features
- **Fully Responsive**: Mobile-first design with smooth breakpoints
- **Fast Loading**: Optimized images and efficient component structure
- **Accessibility**: Proper ARIA labels, focus states, and semantic HTML
- **SEO Ready**: Proper heading structure and meta tags
- **Modern React**: Functional components with hooks
- **Routing**: React Router for seamless navigation

## 🛠 Tech Stack

- **Frontend**: React 19, React Router DOM
- **Styling**: Tailwind CSS, Custom CSS
- **Icons**: Lucide React
- **Typography**: Google Fonts (Lora, Inter)
- **Animation**: CSS transitions and transforms
- **Build Tool**: Create React App with Craco
